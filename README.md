# Web Component Skills

AI agent skills for building and reviewing Lit web components. Distilled from 4,800+ PR reviews across the [PatternFly Elements](https://github.com/patternfly/patternfly-elements) ecosystem.

## Skills

| Skill | What it does |
|-------|-------------|
| [`create-component`](create-component/SKILL.md) | Build a new Lit component from scratch or a reference implementation |
| [`review-a11y`](review-a11y/SKILL.md) | Accessibility audit — axe-core, APG conformance, cross-browser a11y tree, keyboard |
| [`review-api`](review-api/SKILL.md) | API surface checklist — attributes, slots, events, CSS, Lit patterns |
| [`review-pedantic-semantic`](review-pedantic-semantic/SKILL.md) | Semantic HTML, material honesty, typography, links vs buttons, dropdowns |

[`ADVICE.md`](ADVICE.md) is the shared reference doc on web component API design that all skills draw from.

## Usage

Copy any skill directory into your project's `.cursor/skills/`, `.claude/skills/`, or equivalent. Skills are standalone — use one or all of them.
