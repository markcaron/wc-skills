# Web Component Skills

AI agent skills for building and reviewing Lit web components.

## Skills

| Skill | What it does |
|-------|-------------|
| [`create-component`](create-component/SKILL.md) | Build a new Lit component — modular phases from API design through tests and docs |
| [`review-a11y`](review-a11y/SKILL.md) | Accessibility audit — a11y tree verification, APG conformance, keyboard, cross-root ARIA |
| [`review-api`](review-api/SKILL.md) | API surface review — attributes, slots, events, CSS parts/props, Lit patterns |
| [`review-docs`](review-docs/SKILL.md) | Documentation review — JSDoc, CEM annotations, inline comments, slot/part descriptions |
| [`review-pedantic-semantic`](review-pedantic-semantic/SKILL.md) | Semantic HTML nitpicks — material honesty, headings, links, tables, dropdowns, typography |
| [`review-tests`](review-tests/SKILL.md) | Test suite review — coverage, a11y assertions, keyboard nav, form submission, patterns |

[`ADVICE.md`](ADVICE.md) is the shared reference doc on web component API design that all skills draw from.

## Usage

Copy any skill directory into your project's `.cursor/skills/`, `.claude/skills/`, or equivalent. Skills are standalone — use one or all of them.
